The source file mixes encodings for the same facts. Every change below is mechanical and reversible; nothing was inferred beyond the rules listed here.

  • Sample IDs trimmed and upper-cased (sample_1, 'SAMPLE_1 ' → SAMPLE_1).
  • Chromosomes stripped of the chr prefix so chr6 and 6 collapse to one variant.
  • Booleans unified from TRUE/True/yes/1 and FALSE/False/no/0.
  • Talos category 4 holds a sample ID, not a boolean; it is read as de novo only when it matches that row's own sample.
  • Modes of inheritance mapped to full phrases (AD and Autosomal Dominant are the same thing).
  • Genotypes parsed out of the embedded JSON and used to infer parental origin and compound-heterozygous phase.
  • Protein changes stripped of accession prefixes and parentheses, and converted to three-letter code (p.P405S → p.Pro405Ser).
  • HGVSc kept only where it is real HGVS; pseudo-notation such as 135912503G>A was dropped in favour of the genomic coordinate.

  • ClinVar synonyms merged (P/LP, VUS).
  • Null markers missing, . and empty all treated as no data.
  • Dates converted to ISO (14/08/2026 → 2026-08-14).
  • Duplicates merged on sample + position + alleles: 16 source rows → 13 unique variants.
